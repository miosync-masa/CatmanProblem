# Results

All files in this directory are regenerated by `03_Analysis/run_all.py`.

Key tables:

- `manipulation_target_effects.csv`: targeted continuity changes, paired effect sizes, and selectivity indices.
- `manipulation_selectivity.csv`: full intervention-by-perceived-dimension difference matrix.
- `judgment_effects.csv`: five query-specific paired effects for each main contrast.
- `judgment_profile_tests.csv`: within-participant permutation tests of profile heterogeneity with FDR correction.
- `judgment_profile_sensitivity.csv`: primary versus attention-inclusive profile tests.
- `parallel_classification.csv`: transparent count/proportion definitions for joint-high and transitivity-like discordance patterns.
- `data_quality_checks.csv` and `sample_flow.csv`: audit totals.

`Figures/` contains both 300-dpi PNG and vector PDF versions.

`CatMan_results_workbook.xlsx` collects the main sample-flow, data-quality, manipulation, judgment-profile, Parallel, and condition-map tables in one human-readable workbook. The CSV files remain the canonical machine-readable outputs.
