# The Cat-Man Problem

## Working title

**The Cat-Man Problem: Conceptual Decomposition, Interventional Thought Experiments, and Empirical Diagnosis of Same-Person Judgments**

This repository contains the materials, de-identified data, analysis code, numerical results, figures, and decision record for a pilot/exploratory study. The Cat-Man Problem is treated as a general form of inquiry rather than a theory of personal identity:

1. conceptually decompose an apparently unitary question;
2. intervene on its proposed evidential supports in a controlled thought experiment; and
3. empirically diagnose whether observed judgments remain unitary or divide by cue, query, or observer.

The present study is the first worked example, using the natural-language question of whether a post-intervention individual is the same person as a pre-intervention individual.

## Study overview

- Design: 10 vignette conditions presented within participants.
- Item arms: judgment versus manipulation, assigned between arm-sessions.
- Judgment arm: 51 completed sessions; 49 passed the attention check and form the primary analysis sample.
- Manipulation arm: 50 completed sessions; all 50 passed the attention check.
- Unique participants: 99.
- Two participants completed both arms; arms are therefore not treated as fully independent samples for cross-arm inference.
- Attention rule: the prespecified correct response was internally coded as option `0`. Two judgment-arm sessions selected another option and were excluded from the primary analysis. Sensitivity tables also report the full judgment sample.
- Response scale: 1–7 for all analyzed rating items.
- Study status: pilot, exploratory, and proof-of-concept. It was not preregistered and is not intended to estimate population prevalence precisely.

## Minimal empirical claim

The evidence manipulations selectively altered the targeted observer estimates:

\[
E_k \longrightarrow \hat C_k^{(O)}.
\]

However, the downstream mapping from estimated continuity to judgment was not uniform:

\[
\hat C_k^{(O)} \longrightarrow J_q^{(O)}
\]

depended on both the manipulated cue and the query. This is a structural proof-of-concept claim, not a universal theory of personal identity.

## Primary outcomes

The judgment arm measured identity, likeness, relationship, obligation, and treatment judgments. The manipulation arm measured perceived body, memory, functional, self-, and transition continuity. Deny and Parallel anchors included dedicated exploratory items.

## Reproducing the results

From `03_Analysis/`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run_all.py
```

This regenerates the analysis-ready datasets, effect-size tables, 95% confidence intervals, 100,000-permutation profile tests, false-discovery-rate corrections, correlations, sensitivity analyses, Parallel classifications, and all PNG/PDF figures.

## Repository structure

- `01_Study_Materials/`: condition map, item map, presentation logic, and the status of verbatim deployed materials.
- `02_Data/Raw/`: de-identified response- and session-level source data.
- `02_Data/Analysis_Ready/`: attention-filtered long-format datasets generated by `00_clean.py`.
- `02_Data/codebook.csv`: variable dictionary.
- `03_Analysis/`: deterministic analysis and figure-generation scripts.
- `04_Results/`: machine-readable result tables and publication figures.
- `05_Protocol_and_Decisions/`: pre-data design decisions, post-data interpretations, and analysis decisions.

## De-identification

Original platform identifiers were replaced with sequential study IDs (`P001`–`P099`). The mapping is not included. Exact timestamps, start/end times, user-agent strings, and unreviewed free-text responses were removed. Exact age was converted to five-year/ten-year age bands for the public session table.
