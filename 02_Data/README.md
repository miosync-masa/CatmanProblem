# Data

`Raw/` contains public, de-identified exports derived from the final Google Sheet. It preserves all rating rows and the session metadata needed for exclusions and order checks while removing direct or quasi-identifying fields.

`Analysis_Ready/` is regenerated by `03_Analysis/00_clean.py`. Primary analysis files include only sessions with `attention_pass == 1`.

De-identification changes:

- original participant/platform IDs replaced by `P001`–`P099`;
- exact timestamps and start/end times removed;
- user-agent strings removed;
- unreviewed free-text responses removed;
- exact age converted to bands;
- the ID mapping is not included.

The two participants who completed both arms retain the same anonymous ID across arms.
